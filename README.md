# TailHome Monorepo

This repository is organized as a monorepo for TailHome and future related packages.

## Apps

- `apps/tailhome` - one-command private homelab installer for Raspberry Pi OS, Debian, and Ubuntu.

## Quick Start

From a cloned checkout:

```bash
./install.sh
```

Run validation:

```bash
apps/tailhome/scripts/validate.sh
```

See `apps/tailhome/README.md` for TailHome usage, configuration, and service details.
